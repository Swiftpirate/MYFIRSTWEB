About Me

My name is Yande Sichula, and I am a Data Science student at Mulungushi University in the School of Engineering and Technology. I am currently taking ICT251 Web Technologies, which is teaching me how to structure, style and bring web pages to life using HTML, CSS and JavaScript. Outside of web development, my coursework also covers data structures, Java programming and statistics, all of which feed into my long-term goal of building data-driven applications. I enjoy the problem-solving side of programming, and building this personal website has been a practical way to see how the building blocks of the web fit together, from semantic markup to responsive design.

Projects & Skills

Four things I have learned so far. Open a card to see what each skill involves and where I have used it.

Web · ICT251

Semantic HTML5

Structuring pages so that people, browsers and screen readers can all follow them.

What I learned

  • Using header, nav, main, section and footer to give a page a clear outline with a single h1.
  • Writing alt text and captions for images, and a caption and header cells for tables.
  • Labelling every form control so it is clear what each field is for.

Used in: this website, from Activity 1 to Activity 3.

Web · ICT251

Responsive CSS

Styling one page so that it is comfortable to read on a phone and on a laptop.

What I learned

  • Keeping all styles in one external stylesheet that uses element, class and id selectors.
  • Using the box model (padding, borders and margins) to space content consistently.
  • Using Flexbox, Grid and media queries so the layout adapts to narrow screens.

Used in: the layout, gallery, table and forms on this page.

Web · ICT251

JavaScript and the DOM

Making a page respond to what a visitor clicks and types.

What I learned

  • Listening for events such as button clicks and form submissions.
  • Checking user input and showing clear feedback without reloading the page.
  • Using functions, variables and arrays to update the page with textContent.

Used in: the contact form, these project cards, the photo viewer and the study calculator.

Java and Data Structures
